# MAngband Effect Inventory

Date: 2026-08-03  
Scope: Phase 1 evidence inventory for reusable gameplay effects across source channels

## Classification Legend

- Payload Equivalent: same gameplay payload appears across multiple sources.
- Policy Variant: payload is shared but preconditions, scaling, or legality differ by source.
- Source Specific: payload or mechanism is tied to one source family.
